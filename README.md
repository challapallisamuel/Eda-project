# Mobile Sales Data Analysis (EDA Project) From Flipkart.

# Overview
This project performs Exploratory Data Analysis (EDA) on a MObile sales dataset from flipkart through Web scraping to identify patterns, trends, and insights. 
The goal is to understand customer behavior, product performance, and revenue trends.

# Objectives
- Webscarping the data through Beautiful soup and regex formulas
- Understand dataset structure
- Handle missing values
- Analyze sales trends
- Identify top-performing products
- Generate business insights

# Dataset
- Source: Data from website

# Features:
- Order ID
- Product Name
- Category
- Sales
- Quantity
- Date

# Tools Used
- Python 
- Pandas
- NumPy
- Matplotlib / Seaborn
- Jupyter Notebook

# Data Cleaning
- Removed null values
- Converted date columns
- Removed duplicates
- Handled outliers
